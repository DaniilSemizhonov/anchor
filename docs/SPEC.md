# Anchor: СДВГ-контролёр для macOS

> Документ — задание для разработки, по нему Claude Code на Mac собирает приложение.

## Идея

Маленькая панель поверх всех окон, в том числе поверх полноэкранных приложений. По ней одним взглядом видно, **что я сейчас делаю и какой следующий шаг**. Задачи накидываются за секунды хоткеем или перетаскиванием файла. Приложение мягко замечает, что я отвлёкся, и помогает вернуться. Задачи живут в Obsidian.

Принципы:
- **Не отбирать фокус.** Нажатие на панель не выкидывает из игры, IDE или видео.
- **Ввод за 3 секунды.** Мысль не должна успеть убежать.
- **Не стыдить.** Никаких красных счётчиков проваленного и громких звуков. Только мягкие подсказки.
- **Obsidian — источник правды.** Приложение лишь удобное окно к задачам.

## Сценарии

1. Работаю, отвлёкся, смотрю на таблетку: «🎯 Конспект по матану → шаг: формулы Тейлора · 23 мин». Понял, вернулся.
2. Пришла мысль «купить батарейки»: `⌥Space`, ввожу текст, `Enter`, через 3 секунды я снова в работе.
3. Прислали PDF: перетаскиваю на таблетку, дописываю «прочитать гл. 3 к пт», получаю задачу с вложением и датой.
4. Залип в Telegram на 5 минут: таблетка мягко пульсирует и спрашивает, по делу ли это.
5. Вернулся после перерыва: карточка «Ты делал X, остановился на Y, тебя не было 40 мин» и кнопка «Продолжить».
6. Вечер: задачи уже в Obsidian, в ежедневной заметке лог фокуса за день.

## Интерфейс

### Состояния панели
| Состояние | Как выглядит | Как попасть |
|---|---|---|
| **Таблетка** | ~320×36, Liquid Glass: задача · текущий шаг · таймер | по умолчанию |
| **Развёрнута** | задача с шагами, крошка «где остановился», вложения, «Дальше» (3–5 задач), счётчик парковки | наведение / клик |
| **Полоска** | 4 px цветная полоска у края экрана | утащить к краю; наведение выдвигает |
| **Тишина** | скрыта на N минут (созвон, кино) | меню / хоткей |

Панель перетаскивается, прилипает к краям и углам, позиция запоминается для каждого монитора.

### Жесты на панели
- **Свайп вправо** по задаче или шагу: готово (с тактильным откликом трекпада).
- **Свайп влево**: отложить (позже сегодня / завтра / в парковку).
- **Скролл по таблетке**: переключить текущую задачу.
- **Двойной клик**: редактировать.
- **Перетаскивание в списке**: менять порядок.
- **Долгое нажатие на таймер**: пауза.

## Быстрый ввод

Хоткей **`⌃⌥Space`** (настраивается; только-⌥ сочетания macOS 15+ запрещает) открывает поле ввода по центру экрана, как Spotlight.

Синтаксис:
| Ввод | Результат |
|---|---|
| `текст` | задача во «Входящие» |
| `завтра`, `пт`, `30.10`, `через 3 дня`, `к пятнице` | дата `📅` |
| `#тег` | тег, автодополнение только из существующих тегов хранилища |
| `!` | важное (`⏫`) |
| новая строка `> шаг` | подшаги |
| `⌘Enter` | сразу сделать текущей |
| `Tab` | в парковку (это мысль, а не задача) |

Остальные хоткеи:
- `⌥⇧Space`: **оставить крошку** у текущей задачи («остановился на…»).
- `⌥⇧D`: текущий шаг готов.
- `⌥⇧H`: спрятать / показать панель.

- Пробел по вложению открывает Quick Look, двойной клик открывает файл.
- Позже: пункт «Отправить в Anchor» в меню «Поделиться».

## СДВГ-фишки

### Текущая задача и следующий шаг
Текущая задача всегда одна. Крупно показывается только **следующий шаг**, а не весь список.

### Таймер фокуса
Показывает, сколько я на текущей задаче. На 25 и 50 минутах лёгкое мерцание и предложение перерыва. Ничего не навязывает.

### Детектор отвлечений
- Следит за активным приложением через `NSWorkspace` (разрешения не нужны).
- **Рабочие приложения** у каждой задачи запоминаются сами (где я был в первые 5 минут), список можно править.
- **Отвлекалки** задаются глобальным списком: Telegram, YouTube, ...
- Опционально: URL вкладки в Safari, Chrome и Arc через AppleScript (разрешение Automation), чтобы отличать YouTube от документации.
- Логика: больше N минут (по умолчанию 3) в нерабочем приложении, и таблетка мягко пульсирует. Больше 2N, и она разворачивается с вопросом:
  > Ты делаешь «Конспект по матану». Это по делу?
  > **[По делу — запомнить]** **[Вернуться]** **[Сменить задачу]** **[Перерыв 10 мин]**

  «Вернуться» активирует последнее рабочее приложение.

### «Где я был»
Срабатывает после простоя (нет ввода больше 10 минут, `CGEventSource`), после сна или разблокировки. Показывает карточку: задача, последний шаг, последняя крошка, сколько меня не было. Кнопка **[Продолжить]** открывает последнее рабочее приложение.

### Парковка
Мысли, которые всплывают во время работы, но задачами не являются. В конце сессии или вечером разбираю: в задачу, удалить или в Obsidian Inbox.

### Итоги дня
Над какими задачами работал, сколько минут, сколько раз отвлекался. Записывается в ежедневную заметку.

## Obsidian

### Доступ
- **Вариант А (основной):** хранилище лежит на Mac локально (Obsidian с плагином FNS синхронизирует папку). Приложение читает и пишет файлы напрямую, а изменения отслеживает через FSEvents. Работает офлайн, по устройствам разносит сам FNS.
- **Вариант Б:** REST API своего сервера FNS, если на Mac нет локального хранилища.

### Формат
- `Anchor/Задачи.md`: задачи в формате плагина **Tasks**, чтобы их видели запросы Tasks и Dataview:
  ```markdown
  - [ ] Конспект по матану 📅 2026-10-30 #учёба/вышмат 🆔 a7k2
      - [x] Определения
      - [ ] Формулы Тейлора
      - 📍 остановился на остаточном члене
      - [[Глава 3.pdf]]
  ```
  Каждая задача адресуется по `🆔`, поэтому правки точечные и не ломают текст, который я написал руками.
- `Anchor/Парковка.md`: парковка (или существующий Inbox, на выбор).
- Лог фокуса в ежедневную заметку `YYYY.MM.DD.md`: раздел `## 🎯 Фокус` в конце. **Frontmatter не трогать.**
- Теги только из существующих, новые не создавать.
- Позже, опционально: подтягивать `- [ ] … #task` из всего хранилища.

## Техника

- **Swift 6, SwiftUI**, AppKit для окна-панели. Последние Xcode и macOS, Apple Silicon. Оформление в Liquid Glass (`glassEffect`).
- **Без иконки в Dock** (`LSUIElement`), значок в меню-баре (`MenuBarExtra`) с настройками.
- **Панель:** `NSPanel` со стилями `[.nonactivatingPanel, .borderless]`, `level = .statusBar`, `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .stationary, .ignoresCycle]`, `hidesOnDeactivate = false`. Для ввода текста переопределить `canBecomeKey = true`.
- **Хоткеи:** пакет [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts), запись сочетаний в настройках.
- **Автозапуск:** `SMAppService.mainApp`.
- **Данные:** markdown в Obsidian как источник правды плюс локальный кэш (JSON) для таймеров, статистики и состояния окна.
- **Разрешения:** для MVP не нужны. Automation для браузеров опционально. Accessibility не нужен.
- **Без App Sandbox:** простой доступ к хранилищу и AppleScript. Только для себя: ad-hoc подпись (`codesign -s -`), сборка в GitHub Actions.

### Модули
```
Packages/AnchorCore/  — вся логика без AppKit, тесты идут и на Linux
  LocalDate           — дата без времени, как в Tasks
  AnchorTask          — задача, шаги, крошки, вложения
  TasksDocument       — чтение/запись Tasks-markdown с точечными правками
  QuickCapture        — парсер быстрого ввода
  FocusSession        — таймер фокуса
Anchor/               — приложение macOS
  App/                — точка входа, MenuBarExtra
  Panel/              — NSPanel поверх всего, позиция
  Views/              — таблетка, развёрнутая карточка, (быстрый ввод, «Где я был»)
  Store/              — состояние приложения, локальный кэш
  (Monitors/)         — активное приложение, простой/сон, браузеры
  (Obsidian/)         — файлы хранилища, FSEvents
```
