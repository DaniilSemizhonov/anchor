# Anchor

СДВГ-контролёр для macOS: маленькая панель поверх всех окон (и поверх полноэкранных приложений) показывает, что я сейчас делаю и какой следующий шаг.

Полное описание и план — в [docs/SPEC.md](docs/SPEC.md).

## Что уже есть (0.1)

- Панель поверх всего, не отбирает фокус, перетаскивается и запоминает место.
- Текущая задача, следующий шаг, таймер фокуса с паузой.
- По наведению или клику раскрывается: шаги, «где остановился», поле новой задачи, список «Дальше».
- Быстрый ввод понимает даты (`завтра`, `пт`, `к пятнице`, `30.10`, `через 3 дня`), теги (`#учёба`) и приоритет (`!`, `!!`); следующие строки становятся шагами.
- Ядро читает и пишет задачи в формате плагина Tasks для Obsidian (к приложению ещё не подключено).

## Установка

1. Скачать `.dmg` из [релизов](../../releases) (или `Anchor-app` из последней [сборки](../../actions)).
2. Открыть его и перетащить `Anchor` в «Программы».
3. Приложение подписано без аккаунта разработчика, поэтому macOS его заблокирует. Один раз выполнить:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Anchor.app
   ```
4. Запустить. Иконки в Dock нет, управление — через значок в строке меню.

Требуется macOS 26 и Apple Silicon.

## Разработка

```bash
swift test --package-path Packages/AnchorCore   # логика, работает и на Linux
brew install xcodegen && xcodegen generate       # Anchor.xcodeproj из project.yml
open Anchor.xcodeproj
```

Запуск с выдуманными задачами: `Anchor.app/Contents/MacOS/Anchor --demo [--expanded]`.
